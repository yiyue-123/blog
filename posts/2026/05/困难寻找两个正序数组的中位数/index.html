困难——寻找两个正序数组的中位数

2026-05-31 LeetCode

/*
* 常规思路 : 先将两个数组合并，然后去判断数组的长度是奇是偶，然后求中位数。
* 缺点 : 时间复杂度O(m+n)过高不满足题意、空间复杂度为 O(m+n)
* 
* 解题思路 : 既然我们是要找中位数。那么我们可以利用分割数组来找。
* 如果数组长度是奇数，我们从索引
* n / 2 划分，并且这个索引对应的值就是中位数，将这个索引以左(包含这个索引)划分为左子数组，剩余为
* 右子数组。左子数组长度 : n / 2 向上取整，右子数组长度 : n / 2
* 如果是偶数，那么划分子数组时，两者各分一半即可。也就是说这个时候的中位数为 (左子数组的最大值
* + 右子数组最小值) / 2。左子数组长度 = 右子数组长度 = n / 2
* 
* 要寻找两个数组的中位数，那么就需要知道这两个数组的总长度，显然长度为 n + m
* 由于刚刚的推导，可以知道不论这两个数组的长度是怎样的奇偶组合，分割之后左子数组的长度都可以看成
* 是 (m + n + 1) / 2，也就是向上取整。
* 由于两个数组的合并可能是顺序也可能是交叉(实际上不合并，只是这么说),所以合并之后的中位数并不能
* 简单的看成分别使用两个数组的中位数相加除以 2 得来！那么就必须手动的去找这个中位数。
* 利用上面的思想，我们可以看成中位数对应着一个分割线将整个数组分成了两半，而中位数刚好在左子数组
* 的最后。而我们如果将合并之后的数组分成两个，左子数组可以看成由两个数组的左子数组组合而成，同理
* 右子数组一样可以得来。我们对于它们怎么组合并不关心。
* 因为，如果合并之后数组长度为奇数，那么中位数为左子数组的最大值，也就是两个数组的左子数组合并
* 之后的最大值，其实这个最大值就是从两个左子数组的最大值中选出来的。
* 如果合并之后的数组的长度是偶数，那么中位数其实就是左子数组的最大值和右子数组的最小值相加除以 2
* 同理，右子数组的最小值为两个右子数组的最小值中更小的那个。
* 
* 那么我们接下来就要划分数组了，该划分大的数组还是小的数组？
* 如果我们划分大的数组，那么最后我们分割线如果刚好就在最右侧，也就是说这一整个数组都被划在了
* 左子数组，那么它的长度为 m 。另一数组的左子数组的长度为 (m + n + 1) / 2 - m，如果 m 足够大，
* 岂不是另一数组的左子数组元素数量为负数？这显然不合理，所以我们只能划分长度较小的数组。
* 
* 先默认从它的中间开始划分，那么它的左子数组元素的数量 (left + right) / 2，也就是二分查找的 mid 
* 探测值。
* 然后我们知道这两个正序数组合并之后还是一个正序数组，所以满足 左子数组最大值 <= 右子数组最小值
* 那么我们现在的左子数组由 num1左子数组 + num2左子数组，右子数组由 num1右子数组 + num2右子数组
* 由于在同一正序数组中肯定满足 左子数组最大值 <= 右子数组最小值。
* 因此剩下要比较的是 num1左子数组的最大值 和 num2右子数组的最小值，
* num2左子数组最大值 和 num1左子数组最大值。如果这两个条件有一个不满足说明划分出错了，连最基本的
* 正序数组都满足不了。
* 
* 然后就是确定这四个子数组的最值了。两个左子数组的最大值 确定着真正的左子数组的最大值，
* 两个右子数组的最小值 确定着真正的右子数组的最小值。
* 由于划分时，有可能会将整个数组划分到一个子数组中的情况，所以需要设置兜底值。
int nums1Left  = (i == 0) ? Integer.MIN_VALUE : nums1[i - 1]; // 全部划入右子数组
int nums1Right = (i == m) ? Integer.MAX_VALUE : nums1[i]; // 全部划入左子数组
int nums2Left  = (j == 0) ? Integer.MIN_VALUE : nums2[j - 1]; // 全部划入右子数组
int nums2Right = (j == n) ? Integer.MAX_VALUE : nums2[j]; // 全部划入左子数组
* 以上的 num1Left 和 num2Left 表示两个左子数组的最大值，
* nums1Right 和 nums2Right 表示两个右子数组的最小值。
* 如果左子数组为空，那么设置一个整型的最小值来填充为左子数组的最大值；
* 同理，如果右子数组为空，也需要为它填补一个整型的最大值。
* 左子数组为空 : 将整个数组划分到了右子数组，那么可以看成剩了一个 "无穷小" 留给左子数组；
* 右子数组同理。
* 
* 如果找到了，我们还需要判断合并后数组的长度的奇偶性来判断这个中位数怎么计算。
* 
* 如果还是没找到，那么需要在合理范围内变化范围。
*/
class Solution {
    public double findMedianSortedArrays(int[] nums1, int[] nums2) {
      // 在较短数组上二分
      if (nums1.length > nums2.length) {
          return findMedianSortedArrays(nums2, nums1);
      }

      int m = nums1.length, n = nums2.length;
      int left = 0, right = m;
      int halfLen = (m + n + 1) / 2;

      while (left <= right) {
          int i = left + (right - left) / 2;   // nums1的分割线
          int j = halfLen - i;                  // nums2的分割线

          int nums1Left  = (i == 0) ? Integer.MIN_VALUE : nums1[i - 1];
          int nums1Right = (i == m) ? Integer.MAX_VALUE : nums1[i];
          int nums2Left  = (j == 0) ? Integer.MIN_VALUE : nums2[j - 1];
          int nums2Right = (j == n) ? Integer.MAX_VALUE : nums2[j];

          if (nums1Left <= nums2Right && nums2Left <= nums1Right) {
              // 分割线正确
              if ((m + n) % 2 == 0) {
                  return (Math.max(nums1Left, nums2Left)
                        + Math.min(nums1Right, nums2Right)) / 2.0;
              } else {
                  return Math.max(nums1Left, nums2Left);
              }
          } else if (nums1Left > nums2Right) {
              right = i - 1;   // i 太大，往左缩
          } else {
              left = i + 1;    // i 太小，往右扩
          }
      }
      return 0.0;
  }
}
